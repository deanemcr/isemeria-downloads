# Isemeria for Android

Learn Bohairic Coptic through alphabet, vocabulary and grammar flashcards.

**[Download Isemeria and read the installation instructions](https://isemeria-production.up.railway.app/android)**

Requires Android 8.0 or newer with an up-to-date Android System WebView.
Install updates over your existing copy to keep progress. Do not uninstall first.
